# MediHelp Landing Page

Modern, futuristic landing page for MediHelp featuring glassmorphism UI, animated gradients, and Framer Motion interactions.

## Stack

- React + Vite
- Tailwind CSS
- Framer Motion

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the dev server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

4. Preview the build:

```bash
npm run preview
```
